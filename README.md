
# Diabetes Classification and Clustering

Machine learning project for predicting diabetes classes using supervised classification and unsupervised clustering.

## Classes

- `N` — Non-diabetic
- `P` — Predict-diabetic
- `Y` — Diabetic

## Models

### Classification

- Logistic Regression
- Random Forest
- Support Vector Machine (SVM)
- Artificial Neural Network (ANN)

### Clustering

- K-Means
- Agglomerative Clustering
- HDBSCAN

## Workflow

Data Cleaning → EDA → Preprocessing → Classification → Clustering → Evaluation → Error Analysis

## Best Results

- **Best Classification:** Random Forest — 98.18% accuracy
- **Best Clustering:** Agglomerative Clustering — ARI 0.537
